# Poly(A) tail lengths and content on human and viral RNAs

This repository contains all scripts required to reproduce the analyses of poly(A) tail lengths and content presented in our recent preprint: [Extended poly(A) tails are a shared feature of herpesvirus mRNAs](https://www.biorxiv.org/content/10.64898/2025.12.15.694445v1)

All data were derived from nanopore SQK-DRS002 datasets that can be accessed via the [ENA](https://www.ebi.ac.uk/ena/browser/home) under project accessions PRJEB98222, PRJEB104941, and PRJEB105217.

Processed nanopolish outputs (containing poly(A) tail length estimates for each read) are available via [Zenodo](https://zenodo.org/records/18323721), as are the additional data files used for Figs 3, 4, 6 & 7.
