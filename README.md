# Poly(A) tail lengths and content on human and viral RNAs

This repository contains all scripts required to reproduce the analyses of poly(A) tail lengths and content presented in our recent preprint: XXX

All data were derived from nanopore SQK-DRS002 datasets that can be accessed via the ENA/SRA under project accessions PRJEB98222, PRJEB104941, and PRJEB105217.

Processed nanopolish outputs (containing poly(A) tail length estimates for each read) are available via Zenodo, as are the additional data files used for Figs 3 and 4.
