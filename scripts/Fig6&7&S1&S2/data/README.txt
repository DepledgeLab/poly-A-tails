This folder is designated to contain the (intermediate) files necessary to generate figure 6/7/S1/S2:
- the results from the Ninetails analysis (*ninetails*.tsv), which get created by ../running_ninetails.R

Additionally, the output-tsv files from the nanopolish poly(A)-tail length estimation (*.polyA.tsv) (after splitting them by reference (e.g. human vs HCMV) as described in ../README.txt) are also provided (but not directly needed for the visualisation, as the Ninetails output already contains the nanopolish polya information)

The files can be downloaded from zenodo.
